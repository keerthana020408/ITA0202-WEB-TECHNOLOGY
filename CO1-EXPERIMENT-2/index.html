GET & POST Methods

HTML Form Submission Demonstration

HTTP Request Methods

This experiment demonstrates the difference between GET and POST methods using HTML forms.

📤

GET Method

GET sends form data through the URL.

GET: Data is visible in the browser URL after submission.
📥

POST Method

POST sends form data inside the request body.

POST: Data is sent in the request body and is not displayed in the URL.

GET vs POST

Feature GET POST
Data Location URL Request Body
Data Visible in URL Yes No
Suitable For Retrieving data Submitting data
Bookmarking Possible Not normally used
