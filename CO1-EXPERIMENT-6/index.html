Creating an XHTML-Compliant Web Page

XHTML stands for Extensible HyperText Markup Language. It is a stricter version of HTML based on XML rules.

This webpage demonstrates the basic rules and structure required for creating an XHTML-compliant document.

ABOUT XHTML

What is XHTML?

XHTML combines the features of HTML with the strict syntax rules of XML. Every element must be properly nested and closed.

01

Strict Syntax

Elements must follow proper syntax.

02

Proper Closing

Every element must be closed correctly.

03

Lowercase Tags

XHTML elements are written in lowercase.

XHTML RULES

Rules Demonstrated

  • All tags are written in lowercase.
  • All elements are properly closed.
  • Attribute values are enclosed in quotation marks.
  • Elements are properly nested.
  • Empty elements are self-closed.
  • The XHTML namespace is declared.

Example of self-closing XHTML elements:
